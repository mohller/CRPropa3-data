Empirical photomeson model for nuclei, Morejon, Fedynitch, Boncioli, Biehl & Winter, JCAP 11 (2019) 007, arXiv:1904.07999
Tables exported from AstroPhoMes v0.4-15-g315809a (https://github.com/mohller/AstroPhoMes, superheavy extension up to A = 257)
using the export_tables.py script of the AstroPhoMes repository. The file format is described in DATA_GENERATION.txt.
These tables are independent of the photon field and are copied unchanged into data/PhotoPionProductionEmpirical.
